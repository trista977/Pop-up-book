# 画风：照着照片手绘

所有纸片都用 SVG 画，风格统一为**手绘水彩 + 墨线 + 纸边**，像一本精装立体书。

## 工具（engine/paper-art.js、engine/kit.js）

| 工具 | 用法 |
|---|---|
| `art(w, h, svg)` | 一张纸片的画，w × h 单位，SVG 坐标 0…w·10、0…h·10 |
| `wc(svg, strokeWidth)` | 水彩滤镜 + 墨色描边（`INK`），形状边缘微微抖动 |
| `wcCrisp(svg, k)` | 同上，但 `<text>` 和 `<!--C-->…<!--/C-->` 里的细节留在滤镜外，保持清晰 |
| `rng(n, i => svg)` | 重复 n 次拼起来，用于窗户、栏杆、灯泡 |
| `rand(seed)` | 可复现的随机数，用于星星、纹理、光斑 |
| `lg(id, stops)` | 渐变（放在 `<defs>` 里） |
| `cloud(x, y, s, fill)` | 云 |
| `lamp(h, lit)` | 路灯（立片 + 发光层） |
| `traveller(pose, look)` / `me(...)` | 旅行小人（统一的人物画法） |
| `grain(w, h, o)` | 纸纹，盖在底页最上面 |
| `mirror(a)` / `flipY(a)` | 翻转 |
| 颜色常量 | `P`（纸色）`INK`（墨色）`RED` `GOLD` `NAVY` |

重复窗格、石墙和配角街面优先用 `engine/architecture.js` 的 `windowGrid`、`masonry`、`facadeStrip`，示例见 [fast-authoring.md](fast-authoring.md)。主角轮廓仍按照片绘制。

## 规则

1. **照片 → 简化**：保留辨识度最高的细节，其余简化成色块和重复的窗格。细节示例：
   - 招牌上的字照抄
   - 标志色照实
   - 造型轮廓
   - 一两处小道具，比如电话亭、灯箱、旗子
2. **人物用书里的画法**：圆脸、豆豆眼加高光、腮红、简单衣服。海报上的人物也用这个画法，不要画写实的脸。
3. **描边统一**：用 `wc(...)` 包住形状，描边 1.3–1.6。细小的脸和字放在滤镜外。
4. **字要清楚、在框里**：
   - 招牌、横幅的字用 `textLength` + `lengthAdjust="spacingAndGlyphs"` 适配框宽。
   - 中文用 `Noto Serif SC`，英文用 `Georgia` 或 `Cormorant Garamond`。
   - 底页上的长文字放到 `texts`，用画布渲染。
5. **空气透视**：远景淡、冷、偏灰蓝；主角最饱和、对比最强；前景暖。
6. **底页是一整幅画**：路、河、轨道从底页延伸到远景纸片上，颜色衔接。
7. **背面**：会翻过来、会从侧面看到的纸片，用 `artBack` 印上画。
8. **夜景发光层 `artLit`**：
   - 只画发光的东西：窗、灯泡、霓虹、灯箱。
   - 用暖黄 `#f6cf7a` / `#ffcf7e`。
   - 橱窗分成窗格，不要整块亮黄。
   - 发光层是叠加的：黑色或透明的地方不影响画面，画暗色没有效果。
9. **镂空**：树冠、栏杆、拱门可以镂空，透出后层，用透明区域即可。

## 画面密度：照着标杆的细节量画

对比两个标杆的 page.js：议会大厦一张立面里有 40 个小尖塔、20 根壁柱、3 排 58 扇窗；塔桥的桥塔有窗、横线、角塔、金顶。新页面的主角和中景，细节量要到同一个级别：

- 用 `rng(n, …)` 重复窗、尖顶、栏杆、舱位，数量照着照片数（伦敦眼 32 个舱，议会的窗一排排地画）。
- 一面墙至少三种颜色：底色、暗面或阴影、高光或装饰线。
- 主角的结构线比配角粗一倍。
- 先把主角和中景画满，再加前景小东西；前景不能替代中景。

## 夜景页（照着塔桥那页做）

1. **底页画暗**：河、地面用深蓝、深灰（塔桥：`pageBg('#1d2b45')`），浪纹用稍亮的蓝描。
2. **每张会发光的纸片都配 `artLit`**，和 `art` 同尺寸，只画亮的东西：
   - 天际线：随机散落的小窗 `#ffd27a`，加一排街灯光点
   - 桥塔：窗格、塔尖金顶的光晕、塔底的蓝色泛光
   - 吊索、步道：沿结构线描一道亮线 `#fffbea`，像照片里的轮廓灯
   - 船：舷窗；路灯：灯罩加光晕
3. **光晕**用 `filter="url(#glow)"`（`art()` 自带），配合 `opacity`。
4. **`floorLit`**：底页的发光层，画灯光在水面上的倒影（竖着排的短横线），黑底，加法混合。
5. **`light: 'night'`、`lit: 0`**，让开灯成为机关的结果；静态图里 `shot.lights: 1`。

## 子件单独画

钟面、指针、转轮、桥板、塔的侧翼要动或要有厚度，就各画成一张小 `art`，不要画死在母纸片上。母纸片上留出它们的位置（比如大本钟立片上画一个和钟面一样大的白圆，钟面子件盖在上面）。指针画成竖直向上、转轴在画面中心，转动交给 `pose`。

## 光线预设（`spread.light`）

| 预设 | 照片的时间 | 感觉 |
|---|---|---|
| `morning` | 早上 | 明亮、偏白 |
| `afternoon` | 午后 | 暖白 |
| `golden` | 日落前 | 金橙色、影子长 |
| `evening` | 黄昏 | 偏紫、暗，配 `lit: 1` |
| `night` | 夜里 | 蓝调，配 `lit: 1` |

## 配色思路

- 先从照片里取 4–5 个主色，比如墙面、屋顶、天空、招牌、强调色，写成常量放在文件开头。
- 强调色只用在主角和一两个点睛处，比如红旗、招牌、巴士。
- 底页用低饱和的地面色，让纸片跳出来。
