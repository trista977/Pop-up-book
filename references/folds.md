# 折纸结构：选哪种、放哪里

## 页面布局（一页 = 两个半页，书脊在中间）

```
 Z = -65  ┌──────────────── 远边 ────────────────┐
          │  远景 V 折（Z ≈ -60 … -50）             │
          │  中景 / 主角（Z ≈ -45 … -10）            │
          │  街道、河、广场（底页上画）              │
          │  前景：人物、路灯、站牌（Z ≈ 0 … 40）    │
          │  地名卡（左下）     小机关（右下）       │
 Z = +65  └──────────────── 近边（读者）───────────┘
          X = -100            0（书脊）          100
```

- 读者从近边往远边看，主角放在视线中心偏上（Z ≈ -30 … -15），离书脊不要太近，免得挡住对页。
- 左右两页的高度、体量要平衡；主角在一边，另一边放次要地标或人物。
- 每一层都要留空，后面的层要能被看到。

## 结构选择

| 照片里的东西 | 结构 | 写法 | 尺寸要点 |
|---|---|---|---|
| 天空、远处天际线、山 | V 折背景 | `type: 'v', Z: -56…-60, sigma: -3…-5, wl = wr ≈ 46–96` | 高度要和 Z、翼宽一起试（见下面「V 折能多高」）；颜色淡 |
| 横向长立面（宫殿、一排楼） | V 折 | `type: 'v', Z: -40…-30, sigma: -6…-10` | 可以跨过书脊铺满两页 |
| 单栋楼、塔、雕像、树（主角） | 平行折立片 | `type: 'stand', X, Z, yaw: 0` | `Z + h ≤ 65`；塔可以很高，但要离近边远 |
| 街道两侧的楼 | 侧墙 | `type: 'stand', yaw: ±78, X: ±30…±40` | 合书向外倒；长度 ≈ 76，高 ≈ 52 |
| 街角、转角立面 | 侧墙端头铰接的转角面 | `custom` + `parent: 墙` + 随 `rise` 转 90° | 合书折回贴着侧墙 |
| 一整座桥、一道长立面连同两头的塔 | **一张** V 折（整件印在同一张卡纸上） | `type: 'v'`，`wl = wr ≈ 72–96`，不需要的地方镂空 | 合书不会散；桥面下镂空让船过 |
| 招牌、钟面、指针、轮子、桥板 | 附着子件 | `custom` + `parent` | 位置写在母纸片坐标系里 |
| V 折上的子件 | 附着子件，指明铆在哪一翼 | `custom` + `parent: 'v 的 id'` + `parentPart: 0（左）/ 1（右）` | 坐标原点在书脊处的折痕上 |
| V 折上的塔要有厚度 | 插槽侧翼 | `custom` + `parent` + 随 `rise` 从贴平转到垂直 | 合书时沿插槽转平；`twoSided: true` |
| 车、船、小屋、盒子 | 箱形折 | `type: 'box'` | 合书时盒深一半向前、一半向后摊平 |
| 柱、塔、树的立体感 | 十字插片 | `stand` + `cross` | 两片都要双面印刷 |
| 人物、路灯、站牌、小道具 | 平行折小立片 | `stand` | 前景，高 15–30 |
| 地面、路、河、广场、地图 | 底页本身 | `floor` | 不做立体 |

## 两个标杆页的结构（照着排）

《Memory in London》的威斯敏斯特、塔桥两页是 skill 的质量标杆，完整代码见 `examples/westminster/page.js`、`examples/tower-bridge/page.js`。

**威斯敏斯特**（主角是长立面 + 一座高塔）

| 层 | 纸片 | 结构 | 位置 |
|---|---|---|---|
| 远景 | 天际线 + 树冠 | V 折 `wl = wr = 96`，`sigma: -3` | Z -59，高 24 |
| 中景 | 议会大厦整道立面（两头的塔印在同一张上） | V 折 `wl = wr = 72`，`sigma: -9` | Z -36，高 42 |
| 中景 | 西敏寺双塔，从立面后面探出头 | 立片 | X -84，Z -44 |
| 主角 | 大本钟 | 立片 11 × 62 | X 56，Z -22（-22 + 62 ≤ 65 才收得进） |
| 主角子件 | 钟面、时针、分针 | `custom` + `parent: 'ben'`，各自离塔面 .12 / .24 / .34 | 铆在钟面中心 |
| 前景 | 伦敦眼支架 + 铆在上面的转轮，电话亭，河岸栏杆两段 | 立片 + 子件 | Z 17–30 |
| 地面 | 草地、泰晤士河、河岸步道 | 底页一整幅 | 河在 Z -20 … 19 |

**塔桥**（主角横跨两页）

| 层 | 纸片 | 结构 | 位置 |
|---|---|---|---|
| 远景 | 夜里的天际线，窗户在发光层 | V 折 `wl = wr = 96` | Z -58，高 30 |
| 主角 | 双塔 + 高处步道 + 两侧吊索，**一张卡纸** | V 折 `wl = wr = 96`，`sigma: -4`，步道以下镂空 | Z -20，高 60 |
| 主角子件 | 两座塔的插槽侧翼 | `custom` + `parent: 'bridge'` + `parentPart` | 塔中线 X ±27 |
| 主角子件 | 两块桥板 | `custom`，铰接在塔的内侧面 | 抬起 0…84° |
| 动的东西 | 夜船、三排浪片（左右各一） | 立片，`noCrease`（在槽里滑，不画粘贴线） | 船沿 X 7 从 Z -46 滑到 20 |
| 前景 | 河岸栏杆 + 路灯、绞盘、站牌、小人 | 立片；绞盘轮铆在立柱上 | Z 31–44 |
| 地面 | 深色河面 + 石砌岸 | 底页 | 岸线 Z 28 |

学到的几条：

1. **一个整体就印成一张**。桥、长立面这种“连在一起”的东西不要拆成几张纸片拼，印在一张跨书脊的 V 折上，合书时整张一起折平，不会散、不会穿插。镂空让后面的东西透出来、让船从下面过。
2. **立体感靠子件**：V 折是平的，塔的厚度用插槽侧翼补；钟面、指针、转轮、桥板都是铆在母纸片上的子件。
3. **高的东西往远边放**：大本钟 62 高，所以放在 Z -22；桥 60 高，放在 Z -20。
4. **底页是一整幅画**，河从左页流到右页，河岸是前景人物站的地方。

## V 折能多高

V 折合书时能不能收进页面，取决于 Z、高度和翼宽，没有一个简单公式，以折纸检查为准。报「伸出书页（上边缘）」就降低高度，或者把 Z 往书脊中部挪（更接近 0）。下面是检查通过的组合，可以照着起步：

| 例子 | 纸片 | Z | 高 | 翼宽 wl = wr |
|---|---|---|---|---|
| 威斯敏斯特 | 天际线 | -59 | 24 | 96 |
| 塔桥 | 夜景天际线 | -58 | 30 | 96 |
| 西区 | 街景 | -54 | 48 | 46 |
| 威斯敏斯特 | 议会大厦 | -36 | 42 | 72 |
| 塔桥 | 整座桥 | -20 | 60 | 96 |

## 合书约束（render.mjs 会检查）

- 面向读者的立片合书时向前倒：`Z + h ≤ 65`，左右不超出页边。
- 侧墙合书时向外倒：倒下后的范围在页内，不越过书脊。
- V 折只能跨书脊；两翼合书时落在各自的页面上。
- 盒子：`Z + d/2 + h ≤ 65`（大致）。
- 离开页面的部件必须有 `parent`。

## 常见问题

| 问题 | 改法 |
|---|---|
| 主角太高，合书伸出 | 往远边挪（Z 更小），或改成 V 折 |
| 一排楼是几张分开的纸 | 合成一张侧墙，或侧墙 + 转角面 |
| 前景挡住主角 | 前景往旁边挪，或调低镜头俯角 `pol` |
| 背景空 | 远景 V 折里加天际线、云、树冠 |
| 两页不平衡 | 空的一侧加次要地标、树、人物 |
