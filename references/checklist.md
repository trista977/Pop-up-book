# 检查的边界

自动 paperCheck 仅做近似边界和部分附着/动作检查；custom 子件、运动全程、相互穿插和纸张厚度并未完整验证。通过检查不保证实物可制作。必须查看成图并检查打开/合拢及机关全程。

# 出图前检查

## 折纸（render.mjs 自动检查前三项）

- [ ] 0 个合书伸出页面、越过书脊的纸片
- [ ] 0 个悬空的纸片；子件都有 `parent`
- [ ] 0 个做不出来的动作（浮动、摇晃、V 折自己变角度）
- [ ] 合书时纸片之间不互相穿插（自己想一遍倒下的方向）
- [ ] 会被看见的背面都有 `artBack` / `twoSided`

## 画面（打开 popup.png 看）

- [ ] 主角在画面中心附近，最饱和、最清楚
- [ ] 照片里的 3–6 个标志细节都在
- [ ] 字清楚、没有出框、没有被滤镜扭曲、没有错字
- [ ] 前景没有挡住主角
- [ ] 远景淡、冷，主角暖、亮，有层次
- [ ] 两页体量平衡，没有大片空白
- [ ] 光线和照片的时间一致；夜景发光层亮着，窗格分明
- [ ] 人物用书里的卡通画法

## 质量门槛（向塔桥、威斯敏斯特看齐）

- [ ] 主角有厚度：插槽侧翼、十字插片或箱形折，不只是一张平立片
- [ ] 中景不空：有一道跨书脊的 V 折长立面或一排侧墙，把主角后面和两侧填满
- [ ] 至少一个铆上去的子件（转轮、钟面、指针、招牌、桥板），而且是机关的一部分
- [ ] 车、船这类有体积的东西用箱形折（`box`），不是平片
- [ ] 前景有 2–4 个小立片（人物、路灯、站牌、栏杆），不挤、不挡主角

结构达标还不够，画面也要“满”。两轮新 agent 测试都卡在这里：

- [ ] **中景画的是照片里认得出的那栋楼**：轮廓、屋顶、窗格的节奏照着照片画，颜色比远景饱和；不是通用的方块楼和一排树
- [ ] **主角“重”**：主要的结构线粗（art 里 6–10 px），有填色、有暗面，不只是细线；从镜头那么远看，它是画面里最显眼的东西
- [ ] **照片的构图搬过来**：照片里谁挡在谁前面、谁大谁小，页面上保持（例：巴士在伦敦眼前面，就把巴士放在主角正前方的路上，尺寸接近照片比例）
- [ ] **四块都有东西**：左上、右上、左下（地名卡）、右下（彩蛋）各有内容，不留整块空地
- [ ] **三层颜色分开**：远景淡、冷；中景中等；主角最饱和、对比最强

## 机关

- [ ] 一个主机关，停在最好看的那一刻
- [ ] 拉片在它动的东西旁边

## 分享图（打开 card.png 看）

- [ ] 照片和渲染图没有被裁掉关键部分
- [ ] 标题、中文标题、说明正确，不重叠
- [ ] 地点、时间和页面一致

## 发布（详见 publishing.md）

- [ ] 照片是用户自己的，或 `card.credit` 写明了许可
- [ ] 没有复刻别人的标志、原画；没有照片里没有的品牌
- [ ] 小知识都能查证；时间和照片对得上
- [ ] 地点只到地标级别；没有路人脸、车牌、票据上的个人信息
- [ ] AI 标注在；提醒用户在平台上勾选 AI 声明
