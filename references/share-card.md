# 分享图

`scripts/card.mjs` 把原照片和图像模型生成的立体书图排在一张图上。输入：同一文件夹里的 `photo.jpg`、`popup.png`、`card.json`（以及 `make.mjs` 写的 `photo-meta.json`）。

## 版式（3:4，1080 × 1440，输出 2 倍）

```
┌──────────────────────────────┐
│                              │
│          原照片（满版）        │  focus 调裁切；credit 印在右上角
│                       ◯ 邮戳 │  邮戳：stamp 两行，用照片里的冷色
│~~~~~~~~~~ 撕纸边 ~~~~~~~~~~~~~│
│ Punting on the Cam           │  打字机字体：heading，没写就用 title
│                              │
│      立体书图（popup.png）     │  米色背景会被校正成卡片的纸色，连成一张纸
│                              │
│ PLACE · Cambridge, UK   DATE │  place / date
│        立体页由 AI 辅助绘制    │  固定，不去掉
└──────────────────────────────┘
```

- `popup.png` 的背景要是纯米色：`card.mjs` 取它左上角的颜色，把整张图按这个颜色校正成卡片的纸色（`#f1e9d8`）。
- 立体书图会稍微放大，书的主体放在下半张中间，四周的空白会被裁掉一些。
- 邮戳颜色：从照片里自动取冷色（天空、水、阴影的平均色），也可以用 `cool` 指定。
- 日期：未设置 `date` 才读取拍摄日期；显式写 `"date": ""` 可省略日期。

## card.json

| 字段 | 写法 | 例 |
|---|---|---|
| `title` | 英文地名，2–3 个词 | Cambridge |
| `heading` | 卡片上的标题，默认用 `title`；太长会自动缩小 | Punting on the Cam |
| `place` | 拍摄地，英文，只到地标或城市 | Cambridge, United Kingdom |
| `date` | `YYYY.MM.DD`；一般留空，用照片的拍摄日期 | 2026.10.03 |
| `stamp` | 邮戳上的两行，用 `\|` 分开；默认取 `place` 逗号前后两段 | CAMBRIDGE\|UNITED KINGDOM |
| `focus` | 照片被裁切时保留哪一部分（CSS object-position），默认 `50% 50%`；露出下半部分写 `50% 85%` | 50% 85% |
| `credit` | 第三方素材需核对许可后写：作者 · 许可及链接 · 来源 · 修改说明；署名不替代授权 | Photo: … · CC BY 4.0 |
| `cool` | 指定邮戳颜色，不写就从照片里取 | #436989 |

## 其他尺寸

`--size` 可以改画布：

| 尺寸 | 用途 |
|---|---|
| `1080x1440` | 默认，3:4（小红书） |
| `1080x1350` | Instagram 4:5 |
| `1080x1920` | 竖屏故事 |

## 检查

- 照片的裁切露出了主角，避开了路人和商标。
- 标题没有压到邮戳。
- 立体书图的主角清楚，书和纸底接得自然，看不出方框。
