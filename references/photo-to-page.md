# 读照片、拆层

## 1. 读照片：写一段页面简报

逐项写下来，后面每一步都按它来：

| 项 | 问自己 | 例：examples/west-end/photo.jpg |
|---|---|---|
| 主角 | 一眼最想让人记住的是什么？ | 桑德海姆剧院转角的《悲惨世界》巨幅广告 |
| 地点 | 在哪？有没有真实名字可以写？ | 伦敦沙夫茨伯里大道 |
| 时间 | 光线是早、午、金、黄昏还是夜？ | 夜里 → `light: 'evening', lit: 1` |
| 标志细节 | 哪 3–6 个细节一画出来就认得？ | 蓝色 *Les Misérables* 横幅；街垒上挥红旗的学生；柯赛特画像；红色 LED 灯带“STILL THE WORLD'S MOST POPULAR MUSICAL”；弧形转角顶上的蓝紫霓虹 |
| 主色 | 4–5 个 | 夜蓝、深灰黑、红旗红、灯光暖黄、霓虹紫 |
| 动态 | 什么会动、会变？ | 灯（开关）、街上的人和车 |
| 情绪 | 一个词 | 热闹、期待 |

另外两个例子的主角和机关（照片 → 页面）：

| 例子 | 主角 | 标志细节 | 时间 → 光线 | 主机关 |
|---|---|---|---|---|
| `examples/westminster` | 大本钟 + 议会大厦长立面 | 金色钟楼、白钟面、尖顶；议会的一排小尖塔；伦敦眼；红电话亭 | 午后 → `afternoon`，拨指针到傍晚 | 拨钟的指针：改时间、改光线、整点敲钟 |
| `examples/tower-bridge` | 塔桥整座桥 | 两座哥特式桥塔；高处步道；吊索的白色轮廓灯；步道下的蓝光 | 蓝调夜景 → `night` | 转岸边绞盘：开桥 → 过船 → 亮灯 |

## 2. 拆成五层

| 层 | 放什么 | 结构 |
|---|---|---|
| 远景 | 天空、远处街景、天际线 | V 折背景 |
| 中景 | 主角两侧的建筑、背景地标 | 侧墙 / V 折 / 立片 |
| 主角 | 主角本身 | 立片或侧墙转角面，最饱和 |
| 前景 | 人物、路灯、站牌、小道具 | 小立片 |
| 地面 | 路、河、广场 | 底页 |

**照片只有一个视角，立体页要补全空间。** 照片里看不到的部分（街的另一侧、远处）用同一地点的常识补上，风格和照片一致，但不要编造具体的文字和招牌。

例：西区照片只拍到剧院一侧。页面左边是照片里的剧院；右边补了同一区的另一家剧院（SIX）；远处补了一张街景 V 折；街道上补了巴士和两个人。

**不在伦敦的照片**：不用伦敦地铁站牌，也不要套别的城市交通标志（多半是商标）。需要一个地名提示时，用小人的台词和左下角地名卡；可以画一块没有标志图形的普通路牌，上面只写照片里看得到或公认的真实地名。

## 3. 定视角

- 照片是仰视或平视，立体页默认从近边斜上方看（`pol` ≈ 70°，再按遮挡调整）。主角要面向读者或侧向街道，不能背对镜头。
- 照片里在左边的东西，放在左页；在右边的，放在右页。
- 照片的主体是“立面”时，画成侧墙或面向读者的立片；主体是“全景”时，主角居中，用 V 折做远景。

## 4. 从照片到画面的转换

| 照片里 | 画成 |
|---|---|
| 复杂的建筑立面 | 主要轮廓 + 重复的窗格 + 一两处标志性装饰 |
| 招牌、海报 | 照抄文字和主色；人物改成书里的卡通画法 |
| 灯光、霓虹 | 底色画暗，发光层 `artLit` 画亮 |
| 人群 | 一两个旅行小人，加上剪影 |
| 车流 | 一辆典型的车（箱形折） |
| 树、天空 | 简化的色块、云 |
| 杂物（电线、红绿灯、广告） | 大多省略，除非是标志性的 |

## 5. 和用户确认（可选）

细节拿不准时（某个招牌写什么、要不要把朋友画进去），先问用户；不要编造。
