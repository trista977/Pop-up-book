# 机关：静态图也要“停在动作里”

分享图是一张静止的图，但机关仍然重要：

- 它决定画面停在哪一刻：桥开到一半、船正在过、灯刚亮、两人快碰面。
- 打开 `page.js` 的人还可以在互动版里玩。

每页选**一个主机关**，最多再加一两个小彩蛋。

## 机关清单

| 机关 | 适合照片里的 | 写法 | `shot` 里怎么停 |
|---|---|---|---|
| 拉片 + 轨道 | 车、船、人、电车 | `controls: [{id, X, Z, dir, len, apply: (v, c) => c.set('boat', {X: …})}]`，纸片加 `drag: id` | `pulls: {boat: .4}`，停在路中间 |
| 两人碰面 | 有朋友、情侣、家人 | 一个拉片同时移动两个小人 | `pulls: {meet: .45}` |
| 转盘 / 绞盘 | 开桥、风车、摩天轮 | 轮子 `custom` + `parent` + `dial: (deg, c) => c.tab('open', c.tabV('open') + deg / 720)`，驱动一个隐藏控制量（见下） | `pulls: {open: .6}` |
| 拨指针 | 钟楼、手表、日晷 | 钟面 `custom` + `parent: 钟楼` + `dial`；指针是另两片子件；隐藏控制量 `time` 同时改指针角度和光线 `c.light(a, b, t)` | `pulls: {time: v}`，对准照片里的时间 |
| 铰接翻板 | 吊桥、门、窗、招牌 | `custom` + `parent` + 角度随拉片 | 开到 40–70% |
| 转轮 | 摩天轮、风车、旋转木马 | `custom` + `tick` 转动 + `ownLight` | 停在任意角度，灯亮 |
| 开关灯 | 夜景、招牌、橱窗 | `artLit` + `ctx.lights('toggle')` | `lights: 1` |
| 翻面卡 / 明信片 | 旅行纪念、小知识 | kit `postcard` | 通常不翻，正面朝上 |
| 抽出 | 门票、信件、照片 | 口袋 + 隐藏拉片 | `pulls: {tix: .6}`，露出一半 |
| 小翻页 / 迷你书 | 菜单、路线、说明 | kit `booklet` | 合着 |
| 掀盖 / 盒子 | 礼物、收藏、卡片盒 | `raise` 或 `s.opened` | `open: ['lid']` |

## 一个机关串起整页（标杆写法）

最好的页面只有一个主机关，但它带动整页的故事。两个标杆：

| 页 | 手上做的 | 带动的 |
|---|---|---|
| 塔桥 | 绕圈转岸边的绞盘 | 桥板抬起 → 浪片在槽里起伏 → 夜船从桥后驶到桥前 → 全桥亮灯；倒转全部退回 |
| 威斯敏斯特 | 绕圈拨大本钟的指针 | 时间 15:00 → 19:00，光线从午后变成金色再到傍晚，每过整点敲一次钟 |

写法：**一个隐藏控制量（`hidden: true`）当“时间轴”**，手指操作只改它，`apply` 根据它的值摆好所有纸片。这样天然可逆，静态图也只要写一个 `pulls`。

```js
// 绞盘的轮子：铆在立柱上，手指绕圈转它
{id: 'crank', type: 'custom', anchor: 'center', art: crankWheel, parent: 'crankPost',
  pose: s => { const a = (s.ang || 0) * Math.PI / 180; return {o: [0, 7.2, .5], x: [Math.cos(a), -Math.sin(a), 0], y: [Math.sin(a), Math.cos(a), 0]}; },
  dial: (deg, c) => c.tab('open', c.tabV('open') + deg / 720)},   // 转两圈从 0 到 1

controls: [{id: 'open', hidden: true, X: 1, Z: -46, len: 66, init: 0, apply: (v, c) => {
  c.set('crank', {ang: v * 720});                                         // 轮子跟着转
  const lift = smoothstep(Math.min(1, v / .4));                           // 0 … .4：桥板抬起
  c.set('basL', {lift}); c.set('basR', {lift});
  c.set('ship', {Z: -46 + smoothstep(clamp01((v - .42) / .45)) * 66});    // .42 … .87：船驶过
  c.lights(v > .8 ? 1 : 0);                                               // 船过了，灯亮
}}],
```

要点：

- **分段**：把 0…1 切成几段，每段一个动作，前后接上（先开桥再过船），用 `smoothstep` 让每段有缓入缓出。
- **跨过某个点只触发一次的事**（敲钟、提示语）：在纸片状态里记住上一次的值，比较后触发；提示语用 `c.once(key)`。
- **静态图要和照片对得上**：停在机关里**和照片同一时间、同一光线**的那一刻里最好看的位置。白天的照片不要停在“灯全亮”；“亮灯”留给互动版。机关里可以有光线变化（午后 → 金色 → 傍晚，像威斯敏斯特），静态图停在和照片一样的那一段。夜景照片才 `shot.lights: 1`。
- **静态图**：`shot.pulls` 停在故事最好看的那一刻（塔桥 `open: .6`，船正在桥下）。`shot.lights` 在拉片之后应用，会覆盖 `apply` 里的开关灯。
- **不需要页边拉片**：手指直接转绞盘、拨指针。真要拉片，放在它动的东西旁边（威斯敏斯特的游船拉片就在河上的轨道里）。

## 原则

1. **一定可逆**：拉出去能推回来。
2. **拉片放在它动的东西旁边**，跑在轨道槽里。
3. **能直接拖纸片就别只用拉片**：`drag: tabId`。
4. **机关讲故事**：船过桥开、天黑灯亮、时间对得上照片。
5. **只做纸做得出来的动作**：纸片不浮动、不摇晃；动作来自开合书、拉片、转盘、手指。

## 照片 → 机关的联想

| 照片里有 | 可以做 |
|---|---|
| 路、车 | 车沿轨道开 |
| 河、海 | 船沿河开、浪片摆动（靠拉片） |
| 钟、表 | 拨指针改时间、敲钟 |
| 灯、招牌、夜景 | 开关灯 |
| 门、窗、桥 | 翻板开合 |
| 人 | 小人碰面、挥手 |
| 票、信、照片 | 抽出、翻面 |
